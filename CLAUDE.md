# Instruções para o Agente

Ao iniciar qualquer sessão neste projeto, leia o arquivo `docs/AGENTS.md` antes de agir.

Esse arquivo define o fluxo de desenvolvimento orientado por especificação obrigatório neste projeto. Siga todas as regras descritas nele.

## Resumo do fluxo

Para novas funcionalidades ou mudanças estruturais:
1. Criar `/specs/[nome-da-feature]/spec.md` → aguardar aprovação
2. Criar `plan.md` e `tasks.md`
3. Implementar uma tarefa por vez
4. Criar `review.md` após a implementação

Para correções pequenas (texto, cor, espaçamento, ícone, bug visual isolado): aplicar diretamente, sem os quatro arquivos.

## Regra principal

Nenhum código deve ser implementado antes da criação e aprovação dos arquivos de especificação da funcionalidade.

Leia o `docs/AGENTS.md` completo para todos os detalhes.
